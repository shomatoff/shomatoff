## Featured project

### [FIM Guard](https://github.com/shomatoff/fim-guard)

A multilingual desktop File Integrity Monitor built with Python 3.12 and PySide6. It creates SHA-256 baselines for selected directories and detects added, modified, and deleted files without modifying monitored data.

- Uzbek, Russian, and English interface
- SQLite event history and watchdog continuous monitoring
- JSON and CSV reports
- 23 automated tests with Ruff quality checks
- Linux and Windows packages through GitHub Actions
- [Download FIM Guard v1.0.1](https://github.com/shomatoff/fim-guard/releases/tag/v1.0.1)
